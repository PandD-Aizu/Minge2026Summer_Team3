# ストーリー案メモ

このチャットで話した物語の骨組み、伏線、保留案を記録する

## 物語の骨組み

主人公は夏休みに高額バイトへ応募し、無人島へ来る。実際にはバイトそのものが偽りで、上位存在を恐れる宗教団体が主人公を生贄として島へ送り込んだ。団体の目的は主人公を島へ送り込んだ時点で果たされる

上位存在はこの偽のバイトを面白がり、ラジオ越しに雇い主を装う。主人公は最初、ただの仕事だと信じて指示に従う。提示される契約期間は、チュートリアル後の4週間・28日間。上位存在にとって、主人公を帰すかどうか自体は重要ではない

主人公は働きながら脱出手段を用意し、最後は自力で島を出る方向。船を買えるようにする案は候補で、入手方法や契約終了との関係は未定

## 4週間の展開案

| 週 | 物語での役割 |
| --- | --- |
| 1週目 | 普通のバイトに見える魚釣りから始め、ラジオに小さな違和感を混ぜる |
| 2週目 | 売上ノルマに移り、依頼や会話の不自然さから雇い主への疑いを深める |
| 3週目 | 指定魚を釣る依頼と並行して、島へ連れてこられた本当の理由を匂わせる |
| 4週目 | 契約終了と脱出が近づく中でラジオへの疑いが深まる。ノルマの内容と結末の描写は未定 |

序盤から、ラジオの声と上位存在のつながりを推測できる伏線を散らす。制作側の設定ではラジオの声は上位存在だが、物語では最後まで正体を断定せず、疑いを残す。宗教団体の声が別のチャンネルから漏れる案は保留

## GameOverと時間の伏線

ノルマ未達成時はラジオが残念がるような台詞と演出を入れ、暗転後に主人公が一言話す。その後でプレイヤーが「やり直す」か「タイトルへ」を選ぶ

物語上、主人公は死亡せず、島の時間も巻き戻らない。主人公は意識が途切れた後、記憶や日付の感覚が曖昧になり、同じ週を繰り返していると思う。以前にも経験したような感覚がうっすら残る。「1か月の契約のはずなのに、本当はいつからここにいるのか分からない」という怖さにつなげる

失敗後、ラジオに時折混じるニュースの季節から、外の時間が進み続けていることを匂わせる。たとえば、夏休みの仕事をしているはずなのに、雑音に混じって10月や11月のニュースが聞こえる

季節は失敗回数で一律に進めず、やり直すまでに島で経過した時間を積み重ねて決める。チュートリアルと本編の両方を含め、チュートリアルで1日過ごしたなら1日分、本編で丸1週間過ごしたなら7日分を反映する。ゲーム上の週や所持品を復元しても、この経過時間は維持する

## 未決定の演出

- 季節を知らせるニュースの具体的な文面、混信する場面、主人公が反応するかどうか
- ラジオの正体を序盤から匂わせる具体的な台詞や出来事
- 失敗後に髪が伸びている、花が咲く・枯れるといった見た目の変化を使うかどうか
- 最後の脱出手段と、主人公が島を出る場面の描写

週ごとの集計・精算・保存のルールは[ノルマ仕様メモ](QuotaSystemMemo.md)を参照
