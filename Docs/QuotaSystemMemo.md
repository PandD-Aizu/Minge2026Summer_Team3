# ノルマ仕様メモ

このチャットで合意したノルマの仕様と、今後決める項目を記録する

## チュートリアル

- 夜釣りのチュートリアル開始時に、ラジオで「今夜だけ、魚を1匹釣る」と伝える
- 夜の釣り中は時計を進め、深夜0時を締め切りにする
- 未達成ならGameOver。やり直す場合は、ノルマを紹介する夜パートの開始時点へ戻る
- 達成してチュートリアルを終えた翌朝を、本編の1週目・1日目とする。本編のノルマは進捗ゼロから始める

## 本編の4週間

チュートリアル後の28日間が契約期間。週の初めに、ストーリーに合わせて設定したノルマを1つ発表する

| 週 | 目標 | 集計 |
| --- | --- | --- |
| 1週目 | 魚を合計50匹釣る。50匹は調整用の仮値 | 昼夜や魚種を問わず、その週に釣った数 |
| 2週目 | 魚の売上を目標額まで稼ぐ。目標額は未定 | その週に魚を売った金額の合計 |
| 3週目 | 複数の指定魚をそれぞれ必要数釣る。魚種と匹数は未定 | その週に指定魚を釣った数を種類ごとに集計 |
| 4週目 | 未定 | 未定 |

進捗は行動の実績から自動集計する。売却・調合・買い物で手持ちが減っても、集計済みの進捗は維持する。3週目も釣果で判定するため、魚の納品や回収は行わない。2週目の集計対象は魚の売上とする

発表時に目標と期限を示す。進捗HUDには現在のノルマ・期限・達成数または金額を画面上部に表示する

## 精算とGameOver

1. 7日目も夜釣りを遊べる。22時から拠点のラジオで任意精算を選べる。22時は調整用の仮値
2. 未達成で任意精算を選んだ場合は警告と確認を出す。承諾すればGameOver、取り消せば締め切りまで続行できる
3. 最終期限は7日目の深夜0時。釣り場では帰還を促すダイアログを出し、キャンプへ強制帰還させて精算する。期限時に進行中のミニゲームは、その1回が終わって釣果が確定してから精算する
4. 達成したら夜を終え、次の週の初日の朝に新しいノルマを発表する。最終週の達成後の脱出条件・演出は未定
5. 未達成ならラジオの台詞と演出 → 暗転 → 主人公の台詞 → GameOver画面へ進む。「やり直す」か「タイトルへ」を選べる

本編のやり直しでは、時計・お金・所持品・強化・ストーリー進行などのゲーム状態を、その週の開始時点へ戻す。ラジオの伏線に使う島の経過時間は戻さない。[ストーリー案](StoryIdeaMemo.md)

## 保存と再開

- 夜釣りから帰還して翌朝へ進む直前に「今日までの内容を保存しますか」と確認する
- 「保存する」を選んだ場合はその日までの内容を保存し、通常の再開は保存済みの朝から始まる
- 「保存しない」でも、その日の結果を持ったまま翌朝に進む。終了して再開した場合は最後に保存した朝へ戻る
- 週末は先にノルマを判定し、達成時だけ保存を確認する。未達成なら保存確認を挟まずGameOverへ進む

## 実装状況と未決定項目

- 実装済みの範囲は、夜の練習ノルマの発表、期限表示、釣果による進捗更新。期限の判定、本編ノルマ、セーブ、GameOverの接続は後続作業
- 2週目の目標額、3週目の魚種と必要数、4週目の目標、最終週の達成と脱出のつなぎ方は未定
- 週初めに戻すための復元データと、プレイヤーが選ぶ通常セーブの持ち方は実装時に詰める
