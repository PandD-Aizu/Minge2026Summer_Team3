| 敵の発見 | `VisionEnemyDetectSensor` に範囲への接触による検出がある | 気配消しを反映する具体的な検出条件を決める |

現状の確認はソースと設定ファイルに基づく
Unityを起動・操作して新機能の動作やMCP接続を確認したわけではない

## 先に決める仕様

チェック済みは会話で指定された方針で、Unity側の実装完了を意味しない
未チェックは、実装前に決める仕様

- [x] 掟は毎朝3候補から1つ選び、チュートリアルの初回だけ帰還後の夜に選ぶ
- [x] 掟選びは両方で共通にし、掟確認・交換・強化はゲーム背景の上にUIとして開く
- [x] 初回の夜は上位存在から逃げ帰り、ノルマ提示・掟選び・交換・強化後に再出発して区切る
- [ ] ノルマの数量・期限・納品方法・未達成時の結果を決める
- [ ] 選んだ掟がその日だけ有効か、日をまたいで蓄積するか決める
- [ ] 掟の内容、違反条件、違反時の結果を決める
- [ ] 3候補は固定か、掟一覧から抽選するか決める
- [ ] 朝の掟選択中に時間を止めるか決める
- [ ] 通貨の名称、初期所持金、商品の購入価格、魚の売却額を決める
- [ ] 能力強化の項目、上限、必要な費用を決める
- [ ] 調合に使える魚、必要数、作れる薬を決める
- [ ] 気配消しが「発見距離」「気づくまでの時間」などの何に効くか決める
- [ ] 薬の効果時間、重ねがけ、捕獲時の解除、シーン移動時の扱いを決める
- [ ] 通常の翌朝への進行条件と、捕獲からの帰還を区別する
- [ ] セーブするタイミングと、中断後に再開する場所を決める

モックの「アジ1匹で薬1本」「見つかりやすさ30%低下」「翌朝に解除」「能力は3段階」は未確定の仮設定
特に見つかりやすさの数値を、そのまま現在の敵の発見処理へ適用することはできないため、対象となる判定を先に決める

## 既存コードを使う際の接続先

| 作業 | 接続・再利用を検討する場所 | 注意点 |
|---|---|---|
| 朝・期限切れ | `Assets/_Project/Scripts/Core/GameProgress.cs`、`GameClock.cs` | 日付更新と時間帯変更を重複させない |
| 初回案内 | `Assets/_Project/Scripts/Controller/TutorialController.cs` | 遭遇から釣りへ直行せず、撤退・ノルマ・掟・交換・強化を挟み、再出発時に区切る |
| 所持品 | `Assets/_Project/Scripts/Inventory/Inventory.cs` | 売却・調合・使用で共通の所持数を使い、受け取る数量を正の整数に限定する |
| 魚から薬への交換 | `Assets/_Project/Scripts/Data/Exchange/ExchangeRecipeDefinition.cs` | 既存の魚コスト定義の再利用を検討し、お金の価格とは分ける |
| 交換画面 | `Assets/_Project/Scripts/ExchangePoint/` | 画面の表示と実際の売買処理を接続する　Serviceは現状空のため処理追加が必要 |
| 画面と入力 | `Assets/_Project/Scripts/Input/MenuInputService.cs`、`View/ItemMenuNavigation.cs` | シーン終了や画面の無効化でも入力の所有権を解放する |
| 敵の発見 | `Assets/_Project/Scripts/Enemy/VisionEnemyDetectSensor.cs`、`VisionEnemyController.cs` | 発見範囲内で薬を使ったときの再判定と、追跡開始後に使った場合の扱いを決める |
| 保存 | `Assets/_Project/Scripts/SaveSettings/GameData.cs`、`SaveService.cs` | 音量と会話履歴を保持し、旧形式の不足項目に初期値を用意する |

新しい薬用アイテムを既存の `ItemType` にどう表現するかもW02で決める
既存のEnum値や保存済みIDの意味をずらさない

## 一周の動作確認リスト

- [ ] 初回は昼の案内から始まり、最初の夜に上位存在から撤退できる
- [ ] 初回撤退で夜の魚を入手せず、翌朝へも飛ばない
- [ ] 帰還後、ノルマの告知、夜の掟選び、交換、強化の順に進める
- [ ] 昼の魚を売却しても調合しなくても、再出発でチュートリアルを区切れる
- [ ] 通常の日は朝に掟が3つ出る
- [ ] 朝と初回の夜で共通の掟選択画面が使われる
- [ ] 掟確認・交換・強化を開いても、ゲーム背景と日時・場所が見える
- [ ] 未選択では出発できず、確定すると当日の掟が記録される
- [ ] 掟確認画面と実際の違反判定が同じ内容になっている
- [ ] 昼に釣った魚が、売却・調合の両画面に同じ所持数で表示される
- [ ] 魚の売却で所持金が増え、購入・能力強化で正しく減る
- [ ] 調合では魚だけが減り、薬が増える
- [ ] 薬の使用で薬が減り、敵への効果とHUD表示が一致する
- [ ] 材料・所持金不足、最大レベル、薬の効果中は無効な操作を実行できない
- [ ] ボタンの連打で二重購入・二重調合・二重使用が起きない
- [ ] 拠点と釣り場を往復しても、所持金・所持品・掟・強化が維持される
- [ ] 翌朝に日付と掟が切り替わり、期限の切れた効果だけが解除される
- [ ] 未使用の薬と永久強化は翌日にも残る
- [ ] 捕獲からの帰還と通常の翌朝を混同しない
- [ ] 再起動で復元でき、既存の音量と会話履歴も維持される
- [ ] マウスと既存のキーボード操作で選択・決定・キャンセルできる
- [ ] 表示解像度を変えても文字とボタンが欠けない

## 最初の到達点

まずは仮画像で「初回の遭遇・撤退、ノルマ提示、夜の掟3択、商品3つ、能力3つ、調合レシピ1つ」が使え、初回の再出発まで進める状態を目指す
続けて、通常の日に朝から翌朝まで一周できることを確認する
その後に素材の仕上げと演出を追加する
担当者と日程は、仕様と作業分担を決めた時点でこの表へ追記する
