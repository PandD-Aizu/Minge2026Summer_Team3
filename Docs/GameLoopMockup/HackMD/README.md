# HackMDへの貼り付け方

## 画像と説明を載せる

1. HackMDで新しいノートを作る
2. `TutorialShare.md` の本文をコピーして、エディターに貼り付ける
3. 本文中の `<!-- ここに tutorial-overview.jpg をドラッグして挿入する -->` の位置に、同じフォルダーの `tutorial-overview.jpg` をドラッグする
4. 画像のURLが自動で入ったら、元のコメントは消してよい
5. 「通常ゲームの一日の流れ」には、`daily-overview.jpg` も同じ方法でドラッグして挿入する
6. ノートの共有設定でチームが閲覧できるようにして、ノートのURLを渡す

一覧画像が大きければ、`images` 内の個別画像を対応する各見出しの下へドラッグしてもよい
一覧画像と個別画像は、それぞれ1MB未満にしてある

Markdownの本文を貼るだけではPC内の画像はアップロードされないので、画像ファイルをドラッグして挿入する

## 操作できる版も渡す

1. 一つ上のフォルダーの `tutorial.html` を、チームがダウンロードできる共有場所に置く
2. そのダウンロードリンクを、HackMD本文の「操作できる版」に貼る
3. メンバーはHTMLをダウンロードして、ブラウザーで開く

`file:///C:/.../tutorial.html` は自分のPC内の場所なので、そのURLを送ってもほかの人には開けない
HTML本体を渡せば、画像も含めてファイル1つで開ける
`index.html` と `tutorial.html` は同じ内容の統合版なので、どちらか片方だけでよい
同じHTML内で「チュートリアル」「通常の一日」を切り替えられる
ブラウザー内で直接操作できるURLを共有する場合は、別途Webへの配置が必要

この資料の作成では、HackMDへのアップロードやWeb公開は行っていない
