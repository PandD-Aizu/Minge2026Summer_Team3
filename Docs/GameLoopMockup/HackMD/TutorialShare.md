# チュートリアルと通常ゲームの流れのモック

完成時の雰囲気とチュートリアル・通常ループの流れを、早めにチームで合わせるための見本
画面、台詞、ノルマの数量・期限、掟の内容は仮案
同じファイルの「チュートリアル」「通常の一日」で切り替えて確認できる
掟選びは両方で同じ画面を使い、掟の確認・交換・強化はゲームの背景を残してUIとして開く

## チュートリアルの流れ

昼に魚を釣る → 初めての夜釣りへ → 上位存在と遭遇 → 釣らずに逃げ帰る → ラジオからノルマを知らされる → 今夜の掟を選ぶ → 交換所 → 自分の強化・魚の調合 → もう一度夜の釣り場へ

夜の釣り場へ再到着したところで、チュートリアルをいったん区切る

## 画面の見本

### 1. 初めての夜、上位存在と遭遇する

昼と同じ釣り場へ夜に行くと、海に上位存在がいる
「こっちを見てる……戻らないと！」と、釣りを始めずに引き返す

### 2. 慌てて逃げ帰り、ラジオに報告する

夜の魚を釣らず、息を切らして拠点へ戻る
昼に釣ったアジは持ったままで、後の交換・調合で使える
ここではまだ夜を明けさせず、同じ夜の出来事として続ける

### 3. 「そういえば、ノルマがあるからネ」

危険な目に遭って帰ってきたところで、ラジオがノルマを伝える
見本では「翌朝06:00までに、魚を1匹、集荷所へ納品」としている
今回のモックは再出発までなので、ノルマは未達成のまま

### 4. チュートリアルの今回は、夜に掟を選ぶ

掟は本来、毎朝選ぶもの
今回は初回の説明として、帰還後の夜に3つの中から1つを選んで確定する

- 釣った魚を、海へ返すな
- 夜の海では、走るな
- 呼び声には、必ず応えよ

選んだ掟は確定した時点から翌朝まで有効で、過去の行動には適用しない
通常プレイでは翌朝から、朝に掟を選ぶ想定

### 5. 掟を選んだ後に交換所へ

持っている魚を売ってお金にしたり、道具を購入したりする
交換画面は以前のゲームループのモックから統合したもの
昼の魚を調合に残すために、売らずに進んでもよい

### 6. 強化と調合を試して、もう一度夜の釣りへ

お金で「釣りの腕」「足腰」「集中力」を強化できる
「魚で調合」ではアジ1匹をすりつぶして、気配消しのポーション1本と交換できる
使用すると、敵に見つかりにくくなる効果を表示する

準備後に再出発し、夜の釣り場へ着いたところでチュートリアルの区切り
この区切りの後は「通常の一日を見る」で通常ループの見本へ移動できる

## 通常ゲームの一日の流れ

朝の掟選び → ラジオ → 昼の釣り → 釣果を持って帰還 → 交換 → 強化・調合 → 夜釣りへ → 上位存在の気配をやり過ごす → 夜の釣り → 異形の魚を持って帰還 → 翌朝の掟選び

<!-- ここに daily-overview.jpg をドラッグして挿入する -->

- 毎朝、3つの中から今日の掟を1つ選ぶ
- 昼と夜の魚を釣り、売却、道具の購入、能力強化、魚の調合を試せる
- 通常の夜は、チュートリアルで経験した危険を意識して気配をやり過ごす
- 明け方に戻ったら次の朝へ進み、新しい掟を選ぶ
- お金、所持品、能力強化を翌日へ引き継ぐ　ポーションの使用効果は朝に終わる

チュートリアルと通常ループはそれぞれ進行を保持するため、途中でも切り替えて見比べられる

## 操作できる版

共有した `tutorial.html` をダウンロードして、ブラウザーで開く
画像も埋め込んであるため、このHTMLファイル1つで動く
`index.html` も同じ内容の統合版で、どちらか1つを渡せばよい

<!-- チームの共有場所に tutorial.html を置いたら、この位置にダウンロードリンクを貼る -->

- メインのボタンでチュートリアル18場面、通常の一日14場面をそれぞれ進める
- 上部の「初めての夜」で上位存在との遭遇へ移動できる
- 「帰還と掟」で今回追加したノルマと夜の掟選びを確認できる
- 掟は候補を選んでから確定する
- 掟の確定後、交換 → 強化・調合 → 再出発の順に進める
- 通常の一日は、最後の「翌朝の掟を選ぶ」で次の日へ進める
- 「この流れを最初から」で表示中の流れをリセットできる

## チームで確認したいこと

- 初回に釣らずに逃げ帰る流れで、夜の危険が伝わるか
- 帰還後のノルマ提示と掟の説明が、会話の流れとして自然か
- 普段は朝、チュートリアルの今回は夜、という違いが分かるか
- 掟を決めてから交換と強化で備え、再出発する順番でよいか
- 通常ループの「朝に選ぶ → 釣る → 帰る → 備える → 翌日へ」が伝わるか

ゲーム本体への組み込み前に、流れを相談するためのモック
