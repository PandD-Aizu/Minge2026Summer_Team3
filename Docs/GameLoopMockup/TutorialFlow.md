# チュートリアルの流れのモック

[画面モックを開く](tutorial.html)

初めての夜釣りで上位存在に遭遇し、釣らずに慌てて逃げ帰るパートを追加した案
その帰還では夜を明けさせず、ラジオへの報告、ノルマの提示、特例での夜の掟選び、交換、強化・調合、再出発につなげる
`index.html` の交換・強化と統合し、夜の釣り場へ再到着したところでチュートリアルをいったん区切る
同じファイルの上部に「通常の一日」も用意し、朝の掟選びから翌朝までの繰り返しを確認できる

## 想定する流れ

| 場面 | プレイヤーの体験 | 伝えたいこと |
| --- | --- | --- |
| 島に到着 | ラジオに魚を釣るよう頼まれる | 最初の目的 |
| 昼の釣り | タイミングを合わせてアジを釣る | 釣りの基本操作 |
| 夕方の帰還 | 魚を持って拠点に戻る | 釣り場と拠点の往復 |
| 夜釣りに出発 | 昼と同じ釣り場の暗さと静けさを感じる | 夜の雰囲気 |
| 上位存在に遭遇 | 海にいる何かと目が合い、慌てる | 夜には危険がある |
| 釣らずに撤退 | 「戻らないと！」と急いで引き返す | 釣りより帰還を優先してよい |
| 夜の拠点へ帰還 | 息を切らし、ラジオに報告する | 拠点で一息つく |
| 危険を知る | ラジオから距離を取ることを教わる | 危険を見たら釣りを中断する |
| ノルマを知らされる | 「そういえば、ノルマがあるからネ」と告げられる | 夜の危険を知った後にも、果たすべき役割がある |
| 掟の説明 | 本当は毎朝選ぶが、チュートリアルの今回は夜に選ぶと聞く | 通常の時間帯と今回だけの特例 |
| 今夜の掟を選ぶ | 3つの掟から1つ選び、確定する | 選んだ時点から翌朝まで、その掟を守る |
| 交換所 | 魚の売却や道具の購入を試す | 魚をお金に換え、備える |
| 強化・調合 | お金で能力を強化するか、魚をポーションにする | 魚とお金の使い道を選ぶ |
| 再出発の準備 | 掟と準備を確認する | 危険を意識してもう一度出発する |
| 夜の釣り場へ再到着 | 周囲を確認し、釣りに取り組もうとする | ここでチュートリアルをいったん区切る |

## 初回の遭遇と撤退の扱い

- 初回は釣りを始める前に遭遇する
- モックではボタンで逃げる演出を確認し、必ず帰還できる
- 初回の撤退では新しい魚を入手せず、夜釣り達成として扱わない
- 昼に釣ったアジは持ち越し、初回撤退後の交換・調合で使える
- 帰還時刻は同日の22:10とし、翌朝に飛ばさない
- ラジオの会話でノルマを提示し、今夜の掟を選んでから、交換と強化を行い同じ夜に再出発する
- 再挑戦では初回用の強制撤退を繰り返さない
- 夜の釣り場へ再到着したところでチュートリアルの章を区切る　以降は別の「通常の一日」の見本へ切り替えられる

## 初回のノルマと夜の掟選び

- ノルマは「翌朝06:00までに魚を1匹、集荷所へ納品」とする仮案
- 初回撤退まではノルマを表示せず、ラジオが言い出してから画面にも表示する
- 魚の売却や調合はノルマの納品とは別扱いで、今回のモックでは進捗は0 / 1のまま
- 納品による達成と、翌朝に新しい掟を選ぶ処理は再出発後の通常プレイとして扱う想定
- 本来の掟選びは毎朝行うが、チュートリアルの初回だけ帰還後の夜に行う
- 「釣った魚を、海へ返すな」「夜の海では、走るな」「呼び声には、必ず応えよ」の3つから1つ選ぶ
- 候補を選ぶまで確定できず、確定後は選んだ掟を画面に表示する
- 初回遭遇からの逃走は掟を選ぶ前なので、夜に走っても今回の掟違反にはならない
- 選んだ掟は確定した時点から翌朝06:00まで有効とし、過去の行動には適用しない
- チュートリアルの章は翌朝の前で区切る　別の「通常の一日」では朝の掟の選び直しまで操作できる

## 交換・強化の扱い

- 掟選びの画面は通常の日もチュートリアルと共通にし、朝・夜の案内文だけを変える
- 掟確認、交換所、強化・調合はゲーム背景の上にUIパネルとして開き、日時と場所を残す
- 掟を確定すると `index.html` 由来の交換所へ進み、その次に自分の強化へ進む
- 初回の夜に出る前の簡易な売買場面は削除し、交換は掟を選んだ後にまとめる
- 昼に釣ったアジ1匹を、売却するかポーションの調合に使える
- 売却と調合は同じ所持品を消費するので、両方に使うことはできない
- 所持金を使った道具の購入と3項目の能力強化を試せる
- 購入・強化・調合は必須操作にせず、画面を確認するだけでも次へ進める
- 所持金、所持品、強化、ポーションの効果は再出発まで共通の状態として引き継ぐ
- 「この流れを最初から」で表示中の流れを初期化する

## 実装時に関係する箇所

既存の初回遭遇後に撤退、拠点会話、ノルマ提示、夜の掟選び、交換、強化を挟み、再出発したところでチュートリアルを区切る想定

- 上位存在を見た直後は夜釣り成功待ちへ直接進めず、初回撤退用のステップへ進める
- 撤退後に拠点へ戻った場合と、夜の魚を釣って戻った場合を分けて処理する
- 初回撤退の帰還時には、夜釣り完了フラグの更新や明け方への時間変更を行わない
- ノルマの説明と掟の確定を終えたら、交換と強化へ順に案内する
- 掟の確定前に再出発しないよう進行条件を追加する
- 再出発して夜の釣り場へ入ったところで、今回のチュートリアルの完了条件とする
- 以降の魚の入手、ノルマの納品、翌朝への進行は、通常プレイとして別途扱う

## モックの範囲

- チュートリアルはメインのボタンで18場面を順に進め、上部の7つのボタンで章に移動できる
- 「帰還と掟」から初回帰還、ノルマ提示、夜の掟選びを確認できる
- 掟を確定する前に「交換」「強化・調合」「再出発」へ移動すると、掟選びの画面を開く
- 「ひとつ戻る」で直前の場面に戻れる
- 釣りの場面はボタン、または操作中にJキーで成功へ進む
- 交換・強化・調合は実際にボタンで所持金や所持品を変更できる
- 価格、時刻、台詞、ノルマの数量と期限は仮案
- 掟の候補選択、確定、確定内容の表示を再現し、違反による罰の処理は含めない
- 気配消しのポーションを必須にはしていないため、最初の魚を売っても進行できる
- 背景、魚、上位存在は既存素材を再利用し、夜や危険の色調は見本用の演出
- Unityのシーン、チュートリアル制御、時間処理には変更を加えていない
- `index.html` と `tutorial.html` は同じ内容で、どちらも単体で共有できる

## 同じファイルで通常ループも見る

- 上部の「通常の一日」、またはチュートリアル最後の「通常の一日を見る」で切り替える
- 通常ループは14場面で、朝の掟選び、昼の釣り、帰還、交換、強化・調合、夜の異変、夜の釣り、明け方の帰還を確認できる
- 明け方の帰還後に「翌朝の掟を選ぶ」を押すと、次の日の朝へ進む
- 所持金、能力強化、未使用の魚や道具は持ち越し、掟と使用中の気配消しの効果は朝に解除する
- チュートリアルと通常ループの進行・所持品を別々に保持するため、自由に往復して見比べられる
