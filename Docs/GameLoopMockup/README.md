## モックの使い方

上部の「チュートリアル」「通常の一日」で、確認する流れを切り替えられる
各流れの場面・所持金・所持品は別々に保持し、切り替えても見ていたところから再開できる

### チュートリアル

島に到着 → 昼に魚を釣る → 夕方に帰還 → 初めての夜の海へ → 上位存在に遭遇 → 釣らずに撤退 → ラジオへ報告 → ノルマ提示 → 今回だけ夜に掟選び → 交換所 → 自分の強化・魚の調合 → 夜の釣り場へ再出発

- メインのボタンで18場面を順に進める
- 上部の7つのボタンは場面プレビュー用のショートカット
- 初回の夜から戻り、3つの掟から1つ選んで確定すると交換所が開く
- 交換所の「自分の強化へ」で強化と調合の画面へ進む
- 強化画面を終えて出発し、夜の釣り場に着いたところでチュートリアルの区切り
- 最後の「通常の一日を見る」で通常ループの見本へ切り替える
- 「この流れを最初から」で、表示中の流れの所持金・所持品・掟・強化をリセットする
- 通常のブラウザーでは再読み込みでも初期状態へ戻る

交換・強化を最初の夜に行く前に挟む簡易場面は、統合に合わせて後半へ移動した
ノルマは「翌朝までに魚1匹を納品」の仮案で、今回は未達成のまま終了する
チュートリアルの章では夜の釣り場への再出発で区切り、以降の一日の繰り返しは「通常の一日」で確認する

### 通常の一日

朝の掟選び → 朝のラジオ → 昼の釣り場 → 昼の釣り → アジの釣果 → 夕方の帰路 → 夜のラジオ → 交換所 → 強化・調合 → 夜釣りへ出発 → 上位存在の気配をやり過ごす → 夜の釣り → 異形の魚 → 明け方の帰還

- 以前の `index.html` の流れを14場面として追加した
- 最初に朝の3択で掟を選び、翌朝までその掟を守る
- 通常の夜は気配をやり過ごして釣りに進み、チュートリアルの強制撤退は繰り返さない
- 「翌朝の掟を選ぶ」で日付が進み、掟と気配消しの使用効果がリセットされる
- 所持金、未使用の魚・道具・ポーション、能力強化は翌日へ引き継ぐ
- 昼と夜の釣果は1日に各1回だけ加算し、場面を見直しても増殖しない
- 翌日も新しい掟を選び、同じ流れを繰り返し確認できる
- 通常ループは独立した朝の見本として始まり、チュートリアルの所持品とは混ぜない
- ノルマの告知はチュートリアル側で確認し、通常ループには納品判定を追加していない

## 追加画面の操作

- 掟選びは両方の流れで同じ見出し・3枚のカード・確定ボタンを使い、朝か夜かの案内だけを切り替える
- 掟確認・交換所・自分の強化は、ゲーム背景と日時・場所を残したまま、その上に共通のUIパネルを表示する
- 「今夜の掟」「交換所」「自分の強化」は、掟を確定した後に利用できる
- 掟の確認画面には、選んだ掟と有効期間を表示
- 通常は朝に掟を選び、チュートリアルの初回だけ夜に選ぶ　有効期限は翌朝06:00
- 交換所は「購入する」「売却する」を切り替え、品物の所持数と所持金を変更できる
- 自分の強化は「釣りの腕」「足腰」「集中力」の3項目を用意し、所持金で3段階まで強化できる
- 自分の強化の「魚で調合」では、アジ1匹を直接消費して気配消しのポーション1本と交換できる
- ポーションを使うと1本消費し、敵への見つかりやすさが30%低下する効果を表示する仮案
- 効果は翌朝まで有効で、重ねがけはできない　再出発しても効果を表示する
- 調合にお金は不要　同じ魚を売却と調合の両方に使うことはできない
- お金が足りない購入や強化、持っていない魚の売却は選べない
- 昼に釣ったアジ1匹を交換・調合まで持ち越す　場面を見直しても増殖しない
- 交換、強化、調合、再出発の間で所持金・所持品・効果を引き継ぐ

`overview.png` は追加した4画面を並べた共有用画像

背景・魚・上位存在はプロジェクト内の既存画像を使用
UI、セリフの一部、時刻、掟の内容、商品、価格、強化内容は共有用の仮案
掟違反の判定と強化によるゲームプレイへの効果は実装せず、選択状態と数値の変化だけを再現
釣りの判定は成功に固定し、夜の色調は見本用の演出
Unityでの実装ではなく、画面の雰囲気と遷移を確認するためのモック
