## モックの使い方

`index.html` をブラウザーで開くと、ボタンで一日の流れを確認できる
画像を埋め込んでいるため、このHTMLファイルだけをチームへ渡せる

- 朝は3枚のカードから掟を1つ選び、確定して出発する
- メインのボタンで14場面を順に進める
- 上部の「今日の掟」「交換所」「自分の強化」で各画面を開ける
- 下部の7つのボタンは場面プレビュー用のショートカット
- 最後の「翌朝の掟を選ぶ」で日付が進み、新しい掟を選ぶ

朝の掟の選択 → ラジオの案内 → 昼釣り → 釣果 → 夕方の帰路 → 夜の拠点と案内 → 交換所 → 自分の強化 → 夜釣りの案内 → 上位存在との遭遇 → 夜釣り → 異形の魚 → 明け方の帰還 → 翌朝の掟の選択、という流れを確認できる

## 追加画面の操作

- 掟の確認画面には、今日選んだ掟と有効期間、注意する行動を表示
- 掟はその日だけ有効とする仮案で、翌朝に選び直す
- 交換所は「購入する」「売却する」を切り替え、品物の所持数と所持金を変更できる
- 自分の強化は「釣りの腕」「足腰」「集中力」の3項目を用意し、所持金で3段階まで強化できる
- 自分の強化の「魚で調合」では、アジ1匹を直接消費して気配消しのポーション1本と交換できる
- ポーションを使うと1本消費し、敵への見つかりやすさが30%低下する効果を表示する仮案
- 効果は翌朝まで有効で、重ねがけはできない　未使用のポーションは翌日へ引き継ぐ
- 調合にお金は不要　同じ魚を売却と調合の両方に使うことはできない
- お金が足りない購入や強化、持っていない魚の売却は選べない
- 所持金、道具、魚、強化は同じモックを開いている間、翌朝へ引き継ぐ
- ブラウザーで再読み込みすると初期状態へ戻る

`overview.png` は追加した4画面を並べた共有用画像

背景・魚・上位存在はプロジェクト内の既存画像を使用
UI、セリフの一部、時刻、掟の内容、商品、価格、強化内容は共有用の仮案
掟違反の判定と強化によるゲームプレイへの効果は実装せず、選択状態と数値の変化だけを再現
釣りの判定は成功に固定し、夜と明け方の色調は画像加工による見本
Unityでの実装ではなく、画面の雰囲気と遷移を確認するためのモック
